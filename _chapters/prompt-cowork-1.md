* Agent : Cowork
* Prompts

```
[ 목표 ]
지난 3개월간 M365 환경에서의 나의 업무 활동을 분석하여 주요 업무 패턴을 도출하고,
각 패턴별로 Copilot을 활용한 업무 효율화 방안을 도출하고자 한다.
이것을 3장 이내의 임원용 요약 슬라이드로 정리해줘.

[ 분석 범위 ]
- Outlook: 수신/발신 이메일
- Outlook / Teams: 일정, 회의 초대
- Teams: 회의 기록 및 회의 녹음/요약
- SharePoint / OneDrive: 내가 조회, 편집, 생성한 문서
- 기타 M365 서비스에서 발생한 개인 업무 액션

[ 분석 방법 ]
- 유사한 목적과 성격의 업무 활동을 하나의 패턴으로 묶어라
- 상위 카테고리는 최대 5개 이내로 제한하라
- 각 카테고리는 업무 목적 중심으로 명확하게 정의하라

[ 출력 형식 ] 
이것을 3장 이내의 임원용 요약 슬라이드로 정리해줘.
1. 전체 업무 패턴 요약 - 정보근로자 공통 업무 패턴 관점에서 일반화한 용어로 정리하라.
2. 업무 패턴 카테고리별 분석
- 카테고리명
- 해당 카테고리에 포함된 대표적인 업무 예시
- 내가 해당 업무에 사용한 주요 M365 도구
- 반복적·비효율적으로 보이는 지점
3. 각 카테고리별 Copilot 활용을 통한 효율화 아이디어
- Copilot에게 맡길 수 있는 작업
- 자동화 또는 의사결정 보조가 가능한 영역
- 기대 효과 (시간 절감, 품질 향상 등)

[ 주의사항 ]
- 개인 평가나 성과 판단이 아니라, 업무 패턴 인사이트 도출에 집중하라
- 결과는 전략적 인사이트 관점에서 간결하고 명확하게 작성하라
- 임원용 언어를 사용하고 이해하기 쉽게 작성하라.
```
