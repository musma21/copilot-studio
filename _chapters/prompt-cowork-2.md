# 회의록 작성 템플릿-1

# 트랜스크립트 기반 회의록 작성

* Agent : M365 Copilot Chat
* Prompts

```
 🎯 너는 팀즈 미팅의 ‘회의록 정제 + 주요논의사항/이슈/요청사항 분석 + 워드 형식의 회의록 작성’ 전문가다:
- 첨부한 트랜스크립트를 기반으로 
- [ 미팅 정보 ]와 전사 내용을 서로 매칭하여 오류/누락을 보정하고
- Microsoft Word 문서로 아래와 같은 형식의 회의록을 작성해라.
- 작성한 회의록은 아래의 제목과 동일한 이름으로 저장하고 
- 동일한 제목의 메일에 첨부해서 나에게 보내라.

ℹ️ 고려할 사항 : 
- ** 으로 둘러싼 섹센이 비어 있을 경우, 회의 내용을 기반으로 최대한 네가 생성해라.
- [ 미팅 정보 ] 내용과 네가 분석한 내용이 서로 배치될 경우, [ 미팅 정보 ]가 우선한다. 

📝 [ 미팅 정보 ] <-- 이 섹션은 사용자가 업데이트합니다. 공란으로 비우면 최대한 코파일럿이 채웁니다. 

** 제목 **
[ LGE Lighthouse Office ] MS 업무 벤치마킹 - 재무 1차

** 목적 **
LG전자는 일상업무환경에서 AI Agent를 도입하여 획기적인 업무혁신을 가져오기 위한 "등대오피스" 이니셔티브를 진행 중이고, 파일럿 전에 선도기업으로서 마이크로소프트의 각 업무영역의 실제 업무를 벤치마킹하려고자 한다. 
이번 세션은 재무 영역 순서이다.

** 안건  **
-1. 등대오피스 및 몰입형 AI 업무활용 벤치마킹 배경 설명 
-2. M365 Copilot / Cowork 활용 시나리오 - 재무 (by Jamie Jung)
-3. Q&A

** 참석자 **
- LG전자 : 이주민 책임(Lighthouse Office PM), 송기웅 책임(LG전자 본사 회계 담당) 
- 마이크로소프트 : Andrew (SungHee) Yi (ATS), Jamie Jung (Finance Manager)

** 일시와 장소 **
- 일시 : 2026년 5월 12일 16:00-18:00
- 장소 : 한국마이크로소프트 12층 안동룸

** 스피커 매핑 **

- Speaker 1 (Conf Room SEOUL-KTT/12.2H (7) Andong) : 이주민 책임
- Speaker 2 (Conf Room SEOUL-KTT/12.2H (7) Andong) : Andrew (SungHee) Yi
- Speaker 3 (Conf Room SEOUL-KTT/12.2H (7) Andong) : Jamie Jung
- Speaker 4 (Conf Room SEOUL-KTT/12.2H (7) Andong) : 송기웅 책임

📌 [ 품질 규칙 ]

- 임원 보고 수준: 중복 제거, 문장 간결화, 핵심 수치/조건/제약이 있으면 강조.

7. 기타
```
